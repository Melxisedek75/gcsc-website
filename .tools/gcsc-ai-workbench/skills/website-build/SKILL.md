# Premium website build

1. Зафиксируй audience, conversion goal, content hierarchy and brand constraints before code.
2. Используй progressive enhancement: семантический HTML, responsive layout, keyboard access, reduced-motion mode и мобильный fallback.
3. Для motion предпочитай GSAP/ScrollTrigger и Lenis только там, где они улучшают storytelling; WebGL/R3F ограничивай hero или controlled scenes.
4. Не добавляй бесконечные particle effects, autoplay audio, тяжёлый 3D или fake metrics.
5. Перед передачей проверь build, links, responsive states, reduced motion, Lighthouse-like performance indicators и реальные CTA.
