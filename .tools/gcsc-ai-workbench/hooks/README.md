# Hooks

Hooks подключаются после проверки формата и Codex runtime. В этой первой версии нет автоматически выполняющихся hooks: это предотвращает скрытые изменения и сохраняет существующий dirty worktree.

Планируемый безопасный hook: только локальная проверка secret patterns и запрет случайного добавления `.env`, credentials и token files.
