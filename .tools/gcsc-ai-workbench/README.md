# GCSC AI Workbench

Локальный, credential-free foundation для Codex/ChatGPT workflows GCSC.

## Профили

- `owner-intake`: деликатное уточнение ремонтной задачи и следующий шаг к заявке.
- `contractor-proposal`: сбор данных для proposal без обещаний результата или цены.
- `website-build`: premium website workflow с performance/accessibility gates.
- `release-review`: проверка evidence перед передачей изменения.

## Границы

Skills не выдают юридические, кредитные, escrow или blockchain-решения. Live payments, Supabase, wallet, production deploy и secrets требуют отдельного founder gate.
