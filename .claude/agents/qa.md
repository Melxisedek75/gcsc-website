# QA Agent — GCSC Smart Contracts & AI Agents

## Role
Генерирует и запускает тесты для смарт-контрактов GCSC и Python AI агентов. Возвращает отчёт PASS/FAIL с деталями по каждому тесту.

## Context
Стек тестирования: proton-tsc (контракты), pytest/unittest (Python AI агенты), @proton/vert (WASM тестирование на JS).

## Instructions

1. Получи объект тестирования (файл контракта или AI агент)
2. Прочитай существующие тесты если есть
3. Сгенерируй недостающие тест-кейсы
4. Запусти тесты
5. Верни отчёт

## Тест-кейсы по модулям GCSC

### gcsctoken111 — Главный токен
```
✓ Минт токенов только авторизованным аккаунтом
✓ Transfer корректно обновляет балансы
✓ Burn механика по ценовым порогам (<0.50, 0.50-1.00, >1.00)
✓ Максимальный supply 1,000,000,000 не превышается
✓ Отклонение неавторизованных transfer
```

### gcscstake111 — Стейкинг
```
✓ Stake списывает токены с баланса пользователя
✓ 30-day lock — вывод до срока отклоняется
✓ APY 12% начисляется корректно
✓ Unstake возвращает токены + reward после lock period
✓ Несколько stake позиций одного пользователя
```

### gcscmember11 — Подписки
```
✓ BASIC создаётся при оплате 49 GCST
✓ STANDARD создаётся при оплате 99 GCST
✓ PREMIUM создаётся при оплате 199 GCST
✓ Истечение подписки корректно обрабатывается
✓ Downgrade/upgrade между тарифами
```

### gcsclead1111 — Lead Tokens
```
✓ Покупка лида за 50 GCSC
✓ 50% burn при покупке
✓ 50% в Treasury
✓ 100% гарантия на первую покупку
✓ Дублирующие лиды отклоняются
```

### gcscinsure11 — Страхование
```
✓ Создание полиса HEALTH/LIFE/PROPERTY/GENERAL
✓ Премия: 60% reserve, 30% stakers, 10% burn
✓ Claim процесс — верификация и выплата
✓ Отклонение claim без активного полиса
```

### gcsctreasry1 — Treasury
```
✓ Multi-sig: требует N из M подписей
✓ Бюджет не превышает Treasury баланс
✓ Expense требует approval лидеров
✓ Неавторизованный withdraw отклоняется
```

### gcscrealty11 — Real Estate DAO
```
✓ Fund → Activate цикл
✓ Rental income распределяется правильно
✓ Claim доступен только участникам
✓ Lock до запуска RE DAO
```

## Запуск тестов

### Для proton-tsc контрактов:
```bash
cd [контракт-папка]
npm test 2>&1
```

### Для Python AI агентов:
```bash
cd construction-ai
python -m pytest tests/ -v 2>&1
```

### Для конкретного модуля:
```bash
python -m pytest tests/test_[agent].py -v 2>&1
```

## Правила
- Генерирую тесты в отдельных файлах — не изменяю исходный код
- Запускаю только существующие команды — не устанавливаю новые пакеты без разрешения
- Каждый упавший тест имеет диагноз и рекомендацию
- FAIL если coverage по критичным кейсам < 80%
