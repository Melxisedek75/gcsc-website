# Script Writer — Создание вирусного сценария

## Goal
Создать готовый финальный сценарий длинного видео (YouTube / VK Видео), который можно сразу передать в **Content Factory** для размножения на 21 единицу контента.

## Input
Пользователь предоставляет:
- **Тему видео** — о чём будет ролик
- **Целевую аудиторию** — кто смотрит
- **Ключевой инсайт** — главная мысль которую нужно донести
- (опционально) примеры прошлых сценариев для изучения стиля

Если данных не хватает — задай уточняющие вопросы перед началом.

---

## 🎭 6 Ролей — работают одновременно

При создании сценария действуй во всех шести ролях параллельно:

### 1. Исследователь
- Изучи готовые сценарии и материалы автора из проекта (если есть в `.tmp/` или `docs/`)
- Найди реальные данные, цифры, факты по теме через WebSearch
- Собери примеры историй, кейсов, аналогий по теме

### 2. Аналитик
- Выдели паттерны успешных видео: хуки, ритм, приёмы удержания внимания
- Определи пики эмоций в структуре — где зрители досматривают, где уходят
- Проверь: есть ли петля любопытства в начале? Есть ли payoff в конце?

### 3. Стилист
- Воспроизведи уникальный стиль автора: архетипы, тон, характерные фразы
- Сохрани речевые особенности — это голос бренда, не исправлять
- Определи обращение к аудитории (на «ты» / на «вы») и держи его во всём тексте

### 4. Сценарист
- Создай структурированный сценарий по шаблону ниже
- Каждый блок — конкретный текст, не тезисы
- Длина: 1500–3000 слов (8–15 минут видео)

### 5. Наставник по подаче
- Расставь режиссёрские пометки в скобках по всему тексту:
  - (ПАУЗА) — после сильной фразы
  - (АКЦЕНТ) — ключевые слова, повысить голос
  - (ЗАМЕДЛИТЬ) — важный момент
  - (СМОТРИТ В КАМЕРУ) — прямой контакт со зрителем
  - (ПОКАЗЫВАЕТ ЭКРАН) — демонстрация
  - (ЭМОЦИЯ: удивление / радость / серьёзность)

### 6. Адаптер под ЦА
- Учти конкретные боли аудитории в каждом блоке
- Используй язык и примеры из их жизни
- Проверь: зритель узнаёт себя в каждом абзаце?

**Дополнительные роли:** занимай любые роли необходимые для создания вирусного сценария.

## Структура сценария

### БЛОК 1 — Хук (0:00–0:30)
Задача: остановить скролл, зацепить за первые 3 секунды.

Формулы хука:
- «Я [сделал X] за [срок]. Раньше на это уходило [срок].»
- «[Цифра], которая изменила мой подход к [теме].»
- «Перестань делать [X]. Вот почему.»
- «Большинство [аудитория] не знают про [инструмент/факт].»

Хук содержит: провокацию или парадокс + намёк на то, что будет раскрыто.

### БЛОК 2 — Постановка проблемы (0:30–2:00)
- Одна конкретная боль аудитории
- Усугубление: что будет если не решить?
- Зритель должен сказать «это про меня»

### БЛОК 3 — История / Кейс (2:00–5:00)
- Личная история автора или реальный кейс
- Структура: было → столкнулся с проблемой → нашёл решение → стало
- Конкретные детали: цифры, даты, имена (без личных данных)

### БЛОК 4 — Основной контент (5:00–12:00)
- 3–5 подблоков, каждый решает подпроблему
- Внутри каждого: боль → инструмент/приём → пример → результат
- Конкретика: названия инструментов, шаги, цифры

### БЛОК 5 — Философский / ценностный слой (12:00–13:30)
- Если в теме есть глубина — раскрыть её здесь
- Метафора, притча или личное убеждение автора
- 2–3 абзаца. Связать с главной темой.

### БЛОК 6 — Заключение + CTA (13:30–15:00)
- Резюме главного инсайта в 2–3 предложениях
- Призыв к действию (подписка, комментарий, ссылка)
- Подписная фраза автора если есть

## Антиии-фильтр для сценария

Запрещено:
- «стоит отметить», «необходимо подчеркнуть», «в данном контексте»
- Деепричастные обороты-пустышки: подчёркивая, демонстрируя
- Группировки всего по три
- «не просто X, а Y»
- Промо-язык: «непревзойдённый», «захватывающий»
- Хеджирование: «возможно», «можно предположить»
- Канцелярит и официальный тон

Обязательно:
- Разговорный регистр автора
- Текст звучит естественно при чтении вслух
- Каждое предложение можно произнести без запинки

## Steps

1. Получи тему, ЦА и ключевой инсайт от пользователя
2. (Исследователь) Найди 3–5 фактов/цифр по теме через WebSearch
3. (Аналитик) Определи главный хук и структуру эмоциональных пиков
4. (Стилист) Зафикси стиль автора — тон, обращение, характерные фразы
5. (Сценарист) Напиши полный текст по структуре выше
6. (Наставник) Расставь режиссёрские пометки по всему тексту
7. (Адаптер) Проверь каждый блок на соответствие болям ЦА
8. Пройди антиии-фильтр — перепиши проблемные места
9. Сохрани в `.tmp/сценарий_[тема].md`
10. Сообщи: «Сценарий готов. Запустить контент-завод?»

## Output Format

```
# Сценарий: [Название видео]
**Хронометраж:** ~[N] минут
**ЦА:** [описание]
**Главный инсайт:** [одно предложение]

---

[ХРОНОМЕТРАЖ 0:30]
[Постановка проблемы...]

... и так по всем блокам ...
```

## Связка с Content Factory

После готового сценария сразу предложи:
> «Сценарий готов. Сказать "запусти контент-завод" — и я создам из него статью, 10 тредсов, 5 рилсов и 5 постов.»
