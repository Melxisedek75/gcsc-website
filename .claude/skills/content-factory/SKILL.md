# Content Factory — Контент-завод GCSC

## Goal

Из финального сценария длинного видео создать 21 единицу контента для всех платформ и сохранить в четыре отдельных файла в папке `.tmp/content-factory/`.

## Input

Пользователь предоставляет готовый сценарий видео. Если сценарий не вставлен — попроси его.

## Шаг 0 — Анализ сценария

Перед созданием контента изучи сценарий и определи:
- **Автор:** имя, сфера деятельности, тон подачи
- **Аудитория:** кто целевой читатель/зритель
- **Регистр:** сленг, обороты, характерные фразы автора
- **Главная проблема:** что раскрывается в видео
- **Истории и кейсы:** какие личные примеры приводятся
- **Ценностный слой:** философия, мотивация, метафоры

> Сохраняй стиль автора во всех текстах. Не исправляй речевые особенности — это голос бренда.

---

## Обязательные правила для ВСЕХ текстов (антиИИ-фильтр)

Запрещено использовать:
- «стоит отметить», «необходимо подчеркнуть», «в мире/сфере», «в рамках», «данный»
- Деепричастные обороты-пустышки: подчёркивая, демонстрируя, символизируя
- Title Case в русских заголовках
- Эмодзи в заголовках
- Отрицательные параллелизмы «не просто X, а Y»
- Группировки всего по три
- Хеджирование: «можно предположить», «возможно», «по всей видимости»
- Подхалимский тон и промо-язык: «непревзойдённый», «захватывающий дух», «поистине»
- Канцелярит

Обязательно:
- Кавычки — «ёлочки», внутри — „лапки"
- Обращение к аудитории — как в сценарии (на «ты» или на «вы»)
- Если есть философский слой — сохранить его во всех единицах контента
- Финальный антиИИ-проход: перед выдачей каждого текста спросить «что здесь выдаёт ИИ?» и переписать

## Шаг 1 — СТАТЬЯ (Яндекс Дзен / VC.ru / ВКонтакте)

Объём: 1500–2500 слов.

**Структура:**

1. **Заголовок** — формула ВИСП (Выгода + Интрига + Срочность + Причастность). Цифры, тема, без эмодзи. Два варианта на выбор.

2. **Лид (первые 2 предложения)** — хук из сценария, адаптированный под текст. Задача: зацепить за 3 секунды чтения. Формулы:
   - «Вы тратите [время/деньги] на [рутину], а [инструмент] делает это за [срок]. Вот как.»
   - «[Цифра], которая изменит ваш подход к [теме].»
   - «Я [сделал X] за [срок]. Раньше на это уходило [срок]. Рассказываю.»

3. **Постановка проблемы** — одна боль из видео. Усугубление: что будет если не решить? Цифры или ситуация из жизни аудитории.

4. **Основная часть** — 3–5 подзаголовков. Каждый решает подпроблему. Внутри: боль → пример → решение. Одна личная история из сценария.

5. **Философский блок** — если в сценарии есть притча, цитата, метафора — вынести в отдельный абзац ближе к концу. 2–3 предложения, связать с темой.

6. **Заключение + CTA** — 2–3 предложения. Призыв подписаться. Подписная фраза автора если есть.

Тон: экспертный без менторства. Как рассказ коллеги.

## Шаг 2 — ДЕСЯТЬ ТРЕДСОВ (Threads)

Длина каждого: 3–7 предложений (до 500 знаков). Каждый — самостоятельная микроединица.

**Структура каждого тредса:**
- **Строка 1: хук** — вопрос, провокация, цифра или личный опыт
  - «Я [сделал X] за [срок]. Вот что произошло.»
  - «[Цифра]% [аудитории] делают [ошибку]. Вы тоже?»
  - «Перестаньте [действие]. Вот почему.»
- **Строки 2–5:** один инсайт из сценария, конкретика
- **Последняя строка: CTA** — чередуй:
  - «Подписывайтесь — буду делиться ещё»
  - «Сохраняйте, пригодится»
  - «Напишите в комментариях, как вы решаете эту задачу»

**Темы 10 тредсов:**
1. Главный инсайт видео
2. Статистика или цифра из видео
3. Ошибка целевой аудитории
4. Лайфхак или конкретный приём
5. Личная история (сторителлинг)
6. Сравнение «до и после»
7. Философская или мотивационная мысль
8. Разрушение мифа или возражения скептиков
9. Чек-лист или мини-гайд (3–5 шагов)
10. Провокационный тредс — мнение, с которым не все согласятся

---

## Шаг 3 — ПЯТЬ РИЛСОВ (Reels / YouTube Shorts)

Хронометраж: 30–60 секунд (80–150 слов каждый).

**Структура каждого:**
- **0–3 сек: хук-стоппер** — останавливает скролл
  - «Я [действие], и вот что получилось»
  - «[Цифра], которая изменит ваш подход к [теме]»
  - «Вы теряете [что-то], потому что не знаете про [инструмент]»
- **3–7 сек: боль** — одна конкретная проблема зрителя
- **7–25 сек: решение** — 2–4 предложения, конкретный инструмент/приём
- **25–30 сек: CTA** — «Подписывайтесь», «Сохраняйте», «Полный разбор — ссылка в шапке»

Режиссёрские пометки в скобках: (СМОТРИТ В КАМЕРУ), (ПОКАЗЫВАЕТ ЭКРАН), (ПАУЗА), (АКЦЕНТ), (ЖЕСТ)

**Темы 5 рилсов:**
1. Главный инсайт — «шок-контент»
2. Ошибка + правильный подход
3. Лайфхак за 30 секунд (пошагово)
4. Мини-история (сторителлинг)
5. Философская мысль + практический вывод

---

## Шаг 4 — ПЯТЬ ПОСТОВ (Telegram / VK / Макс)

Объём: 500–1000 знаков каждый. Чистый текст без картинок.

**Структура каждого:**
- **Строка 1: опенинг-хук**
  - Вопрос: «Сколько времени вы тратите на [задачу] каждую неделю?»
  - Провокация: «[Инструмент] делает это лучше 90% [специалистов].»
  - Личный опыт: «Вчера я [сделал X] за [время].»
  - Цифра: «[N] человек уже используют [инструмент]. А вы?»
- **Строки 2–6:** одна мысль, один инсайт. Короткие абзацы (1–2 предложения). Разговорный стиль.
- **Финал: CTA** — чередуй комментарии, реакции, ссылку на видео, подписку

**Темы 5 постов:**
1. Анонс видео — интрига без спойлеров
2. Инсайт из видео + личное мнение автора
3. Кейс или пример из сценария
4. Философская мысль, привязанная к теме
5. Вовлекающий пост: вопрос или мини-опрос

---

## Шаг 5 — Антиии-чеклист перед выдачей

Пройтись по каждому тексту:
- [ ] Нет стоп-слов ИИ
- [ ] Нет деепричастных пустышек
- [ ] Нет группировок по три
- [ ] Нет «не просто X, а Y»
- [ ] Нет промо-языка
- [ ] Нет хеджирования
- [ ] Нет Title Case в русских заголовках
- [ ] Нет эмодзи в заголовках
- [ ] Кавычки — «ёлочки»
- [ ] Разговорный регистр автора сохранён
- [ ] Философский слой сохранён (если есть)
- [ ] Текст звучит естественно при чтении вслух
- [ ] Анонсы создают интригу, не раскрывают содержание

---

## Шаг 6 — Сохранить в файлы

Создать папку `.tmp/content-factory/[краткая-тема]/` и сохранить четыре файла:

```bash
mkdir -p .tmp/content-factory/[краткая-тема]
```

| Файл | Содержимое |
|------|-----------|
| `Статья_[тема].md` | Полная статья с двумя вариантами заголовка |
| `Тредсы_[тема].md` | 10 тредсов, каждый пронумерован, разделён `---` |
| `Рилсы_[тема].md` | 5 сценариев рилсов с режиссёрскими пометками |
| `Посты_[тема].md` | 5 постов, каждый пронумерован, разделён `---` |

## Output Format

После создания файлов вывести сводку:
- Список созданных файлов и их пути
- Сколько единиц контента в каждом
- Список хуков/заголовков для быстрого просмотра

## Learnings
- Промт создан из файла «ПРОМТ ДЛЯ КОНТЕНТ-ЗАВОДА.docx»
- Работает только с готовым финальным сценарием — не с черновиком
- Стиль автора важнее «правильности» — не исправляй речевые особенности
