# vidIQ YouTube plugin

Private Agent Plugin package for vidIQ-style YouTube planning and optimization.

Current release: `0.1.0`

This release connects to the official vidIQ MCP endpoint using OAuth 2.0. After installation, authorize the connection with the vidIQ account that owns the channel data you want to analyze.

The connection is read-and-analyze focused. vidIQ MCP does not upload or publish videos and does not edit YouTube channel metadata. Tool calls consume vidIQ credits according to vidIQ's current plan rules.
