# GCSC Whitepaper v1.3 Claim Risk Hardening Checklist

Status: internal claim-risk hardening checklist. This does not approve public publication.

## Purpose

This checklist keeps v1.3 public-facing copy away from regulated, misleading, or overbroad claims while GCSC remains in Construction Trust Infrastructure mode.

## Hard Block List

The following claims must not appear as standalone public promises:

- investment product;
- guaranteed return;
- risk-free;
- passive income;
- staking return;
- yield;
- instant loan approval;
- automatic escrow release;
- live escrow custody by GCSC;
- token collateral as live;
- stablecoin settlement as live;
- public NFT marketplace;
- tokenized property equity;
- guaranteed property value increase;
- SEC-approved;
- regulator-approved;
- Metallicus partnership approved;
- FIO payment requests live;
- XPR settlement live.

## Required Context If Mentioned

| Topic | Required Context |
|---|---|
| Lending | licensed lender/provider review, no current GCSC origination, approval, funding, or servicing |
| Escrow | licensed escrow partner controls custody/release, GCSC creates escrow-ready records only |
| Stablecoins | future provider-reviewed settlement path only |
| Token collateral | future legal/provider/custody/oracle review only |
| FIO Protocol | future optional UX research path only, not compliance or payment approval |
| Metallicus/XPR/Metal/WebAuth | candidate infrastructure path only, no partnership claim |
| Value Mirror | verified performance/value record concept only, not investment return, appraisal, or property equity |
| AI | assists review and evidence organization, does not approve loans, release funds, or make legal decisions |

## Candidate Draft Checks

Before any future publication decision, candidate drafts must pass:

- no hard-block standalone claims;
- every finance/Web3 topic has future/review-required/provider context;
- no partnership, approval, or regulatory endorsement claims;
- no public investment, yield, staking-return, or passive-income framing;
- publication gate remains NO-GO until founder/reviewer evidence is recorded;
- rollback and archive plan are ready.

## Publication Stop Rule

If a sentence can be interpreted as "GCSC already provides regulated finance, escrow, money movement, digital-asset settlement, token collateral, investment upside, or approved partnership," the sentence must remain internal or be rewritten before public use.
