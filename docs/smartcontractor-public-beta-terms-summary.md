# SmartContractor Public Beta Terms Summary

## Purpose

This document is a plain-English terms summary for SmartContractor public beta testers.

It exists so testers understand the public beta is demo only, what they may test, what they must not submit, and which real-money features are disabled.

This is not legal terms, not legal advice, not a full privacy policy, and not a production customer agreement. Final terms require founder review and legal review before wider launch.

## Plain English Terms

By testing the public beta, the tester understands:

- SmartContractor public beta is demo only.
- `PUBLIC_SITE_URL` may change during testing.
- Magic Link login may be used only for the test account the founder invited.
- Screens, bids, loans, payments, disputes, and reviews are test flows.
- X-Request-Id values can be shared for debugging.
- The support queue is for beta issues and safe feedback only.
- A redacted screenshot is acceptable if it contains no private data.

## Tester Responsibilities

Testers should:

1. Use only fake/demo construction data.
2. Report issues with role, device, browser, public beta URL, issue ID, and X-Request-Id when available.
3. Share only redacted screenshot evidence.
4. Stop testing and tell the founder if a screen asks for sensitive information.
5. Avoid uploading real homeowner, contractor, customer, wallet, payment, or legal data.

## What SmartContractor Does Not Promise

During public beta, SmartContractor does not promise:

- no loan approval;
- no investment advice;
- no legal advice;
- no contractor hiring guarantee;
- no homeowner payment protection guarantee;
- no production uptime guarantee;
- no token value or token price outcome;
- no production escrow or lending service.

Any language about loans, escrow, token collateral, contractor seriousness, or payment release is a product concept under founder review, provider review, and legal review.

## Disabled Real-Money Features

These features stay disabled:

- real payments disabled;
- real loans disabled;
- escrow disabled;
- token collateral disabled;
- real contractor payout disabled;
- real homeowner deposit handling disabled;
- live provider onboarding disabled unless the founder explicitly approves it in a separate step.

The beta is for testing product flow, trust language, request tracing, evidence capture, and user understanding.

## Evidence And Privacy Boundaries

Testers must not send:

- no SQL;
- no secrets;
- personal IDs;
- private contact details;
- payment data;
- wallet data;
- real customer addresses;
- database URLs;
- API keys;
- Magic Link tokens;
- service-role keys.

If sensitive data is sent by mistake, the founder should use the public beta data deletion request process and keep only a safe redacted summary if needed for product debugging.

## Founder Review Required

Founder review is required before:

- inviting public beta testers outside the controlled group;
- enabling strict production Auth/RLS;
- changing public beta scope;
- connecting real payment providers;
- enabling real loans;
- enabling escrow;
- enabling token collateral;
- using tester quotes, screenshots, or metrics in partner, grant, investor, or public materials.

## Not Legal Terms

This summary is not the final production terms of service.

Before production launch, SmartContractor needs attorney-approved terms, a final privacy policy, provider agreements, payment/lending/escrow compliance review, and security review.
