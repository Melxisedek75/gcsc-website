# GCSC Whitepaper v1.3 Regulated Web3 Architecture Map

Status: internal architecture map. Research-only. No partnership, endorsement, integration, account setup, provider approval, public publication, FIO registration, XPR signature, wallet connection, stablecoin settlement, token collateral, loan, escrow, custody, or money movement is approved.

## Purpose

This map separates the current GCSC product from future regulated Web3 infrastructure so the project can keep innovation without presenting itself as an unlicensed lender, escrow provider, money transmitter, securities issuer, custodian, insurer, appraiser, or broker.

## Layer 0: Current No-Real-Money Construction Workflow

| Component | Current Role | Allowed Now | Blocked Now |
|---|---|---|---|
| Project records | Store project requests, bids, project-contract records, milestones, evidence, disputes, and request IDs | Local/demo records and review packets | Binding legal contract automation |
| Contractor profiles | Organize contractor business/profile data and review status | Demo profile records, local verification notes | Legal certification of license or insurance |
| Milestone evidence | Track scope, evidence, approval status, dispute state, and audit events | Escrow-ready milestone records | Real escrow release |
| Working-capital readiness | Prepare contractor/project data for future lender review | Local readiness packet | Loan origination, approval, funding, servicing, or adverse-action decisions |
| Payment intent records | Record intended payment rail and review state | Demo-only payment-intent records | Charging cards, moving XPR, settling stablecoins, or routing repayments |
| Admin review | Store local review notes and blocked-live status | Local notes, screenshots, request traces | Live Supabase role changes or real approval authority |

| Partner Category | Partner Role | GCSC Role | Required Before Live Use |

| Valuation/appraisal provider | Provide property data or appraisal-supported workflows | Store valuation context and evidence references | Appraisal/legal review and disclaimers |
| Custodian | Hold digital assets if future regulated records become value-bearing | Reference custody status only | Custody provider review, legal classification, audit controls |

## Layer 3: Future Regulated Digital Construction Records

| Record Type | Intended Purpose | Safe Boundary |
|---|---|---|
| Verified construction performance record | Evidence that work was completed and reviewed | Non-transferable or restricted until legal review |
| Contractor reputation credit | Internal reputation and underwriting context | Not investment, not yield, not public trading |
| Value Mirror record | Evidence of possible value creation from construction activity | Not a guaranteed appraisal, not property equity, not public investment product |
| Milestone audit hash | Proof that a project/milestone record existed at a time | No payment release or legal decision by itself |
| Provider handoff packet | Structured data for a licensed partner review | Partner controls regulated decision |

## Data Flow

1. Homeowner or contractor creates a project workflow record.
2. SmartContractor organizes bids, evidence, milestones, disputes, and request IDs.
3. GCSC produces local review packets and audit logs.
4. If founder/legal/provider gates are approved, a licensed partner may receive a limited data packet.
5. The partner performs regulated action, if any.
6. GCSC records status and evidence without controlling funds or making legal/provider decisions.
7. Future Web3 rails may record non-value audit proofs first, then restricted regulated records only after review.

## Blocked Live Actions

Codex and GCSC must not autonomously perform:

- provider outreach;
- account setup;
- API key use;
- legal conclusions;
- public partnership claims;
- FIO registration;
- FIO payment requests;
- XPR signatures involving value;
- production smart contract deployment;
- stablecoin settlement;
- token collateral;
- Metal X or LOAN Protocol lending/borrowing;
- escrow custody;
- loan origination, approval, funding, or servicing;
- money movement;
- public publication of regulated claims.
