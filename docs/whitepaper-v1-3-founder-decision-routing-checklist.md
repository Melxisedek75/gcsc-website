# GCSC Whitepaper v1.3 Founder Decision Routing Checklist

Status: internal founder decision routing checklist. No founder decision is recorded here.

This checklist does not approve public publication, public website replacement, PDF publishing, provider outreach, reviewer outreach, legal conclusions, provider commitments, live Supabase changes, real payments, real loans, escrow custody, stablecoin settlement, token collateral, wallet signatures, FIO registrations, XPR signatures, or Metallicus/XPR partnership claims.

## Purpose

This checklist routes a future founder v1.3 decision into safe local Codex work without collapsing internal direction, reviewer routing, public publication, and live action into one approval.

## Intake Source

Use this checklist only after the founder records a current-thread decision in:

- `docs/whitepaper-v1-3-founder-decision-intake-template.md`
- or a direct current-thread message using one of the allowed decisions.

Allowed decisions:

- HOLD;
- REVISE;
- APPROVE_LOCAL_DIRECTION;
- ROUTE_TO_REVIEWERS;
- PREPARE_PUBLICATION_LATER.

## Routing Matrix

| Founder Decision | Safe Codex Route | Required Evidence | Still Blocked |
|---|---|---|---|
| HOLD | keep package internal, continue validators and local docs | current decision note | public files, outreach, live finance/Web3 |
| REVISE | prepare local revisions and validators for named sections | exact sections or issues to revise | publication, legal conclusions, provider commitments |
| APPROVE_LOCAL_DIRECTION | keep Construction Trust Infrastructure first as internal direction | current-thread decision and scope exclusion | public replacement, provider outreach, live action |
| ROUTE_TO_REVIEWERS | prepare reviewer packets, redaction checks, and response intake only | named reviewer categories or recipient list from founder | autonomous send, legal conclusion, partnership claim |
| PREPARE_PUBLICATION_LATER | continue evidence, archive/rollback, browser QA, and publication templates | current decision and continued NO-GO acknowledgement | public replacement until separate GO record |

## Required Checks Before Acting

| Check | Required State |
|---|---|
| founder decision is current-thread | YES |
| decision uses allowed option | YES |
| public publication approved? | NO by default |
| public file replacement approved? | NO by default |
| live action approved? | NO by default |
| reviewer send approved? | NO by default unless separate founder-controlled send scope is recorded |
| secrets or credentials included? | NO |
| legal/provider conclusion included? | NO |

## Escalation Rules

Stop and request explicit founder/legal/provider action if the decision includes:

- public publication or public file replacement;
- actual reviewer packet send;
- provider outreach;
- legal, securities, lending, escrow, tax, insurance, appraisal, or contractor-licensing conclusion;
- real payment, loan, escrow, stablecoin settlement, token collateral, wallet signature, FIO registration, minting, staking, bridge, swap, transfer, or XPR action;
- external account login or settings change;
- secrets, API keys, passwords, service-role keys, private keys, seed phrases, or payment data.

## Stop Boundary

This checklist is a routing aid only. It cannot be used to publish materials, replace public files, send reviewer packets, contact providers, make legal conclusions, touch live Supabase, move money, approve loans, hold escrow, settle stablecoins, lock token collateral, register FIO names, or sign XPR actions.
