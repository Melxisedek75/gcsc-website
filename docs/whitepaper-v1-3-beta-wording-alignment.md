# GCSC Whitepaper v1.3 Beta Wording Alignment

Status: internal beta wording guide. This does not approve tester invites, public launch, website changes, provider outreach, live payments, live loans, escrow, stablecoin settlement, token collateral, FIO actions, or XPR signatures.

## Goal

Make beta tester language match v1.3:

```text
Construction Trust Infrastructure first.
Future regulated Web3 construction infrastructure second.
```

## Tester-Facing Safe Message

SmartContractor is a no-real-money construction workflow demo. It helps test project records, contractor bids, milestone evidence, dispute packets, admin review, and request IDs.

It does not move money, approve loans, hold escrow, release funds, settle stablecoins, lock token collateral, or make legal/insurance/credit decisions.

## What Testers Should Evaluate

- Can a homeowner understand the project flow?
- Can a contractor understand bid and milestone records?
- Are demo-only money boundaries clear?
- Are dispute evidence and admin review understandable?
- Does "Construction Trust Infrastructure" feel clearer than crypto-first language?
- Are future Web3 references understandable as future infrastructure, not live finance?

## Blocked Words To Avoid In Beta Copy

- investment;
- token profit;
- guaranteed;
- risk-free;
- instant loan;
- live escrow;
- live stablecoin settlement;
- public NFT;
- passive income;
- regulator-approved.

## Words To Prefer In Beta Copy

- no-real-money demo;
- construction trust workflow;
- verified project records;
- milestone evidence;
- escrow-ready records;
- provider-reviewed working capital;
- admin review;
- future regulated Web3 layer;
- optional future wallet integration.

## Beta Stop Conditions

Stop beta sharing and route to founder review if a tester believes:

- GCSC is holding money;
- a real loan was approved;
- escrow is live;
- token value is promised;
- FIO or XPR actions are live;
- Metallicus partnership is already approved;
- the demo made legal, insurance, credit, or appraisal conclusions.
