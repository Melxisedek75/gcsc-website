# GCSC Whitepaper v1.3 Terms Glossary

Status: internal wording control. Terms are not legal classifications unless counsel approves them.

## Preferred Terms

| Term | Meaning |
|---|---|
| Construction Trust Infrastructure | GCSC positioning as workflow, evidence, reputation, and partner integration layer |
| SmartContractor | First GCSC product layer for project records, bids, milestones, disputes, and admin review |
| Escrow-ready milestone record | A record that can support licensed escrow workflows without GCSC holding funds |
| Partner-powered working capital | Contractor financing reviewed and provided by a licensed lender or finance partner |
| Digital construction record | Future restricted or internal record of verified construction activity |
| Value Mirror | Future reviewed concept for recording verified work, improvement evidence, and value-change context |
| Construction Trust Score | Contractor/project reputation signal based on evidence and performance |
| FIO Handle | Human-readable Web3 handle that may reduce wallet/request friction in future approved flows |
| WebAuth | Future optional wallet/signing UX candidate for XPR workflows |
| XPR audit hash | Future on-chain reference to a project or audit record, not automatically a value transfer |

## Review-Required Terms

| Term | Why Review Is Required |
|---|---|
| loan | lending law, disclosures, adverse action |
| escrow | escrow licensing and custody |
| collateral | lending, secured transaction, token and consumer risk |
| stablecoin | payment, money transmission, stablecoin regulation |
| NFT | securities, consumer perception, speculation |
| token reward | securities, tax, compensation |
| staking | securities/yield risk |
| DAO treasury | governance, custody, fiduciary, securities risk |

## Blocked Public Terms Unless Approved

- guaranteed return;
- risk-free;
- SEC-approved;
- regulator-approved;
- investment token;
- passive income;
- instant loan approval;
- automatic escrow release;
- insured profit;
- public NFT investment;
- tokenized property equity.
