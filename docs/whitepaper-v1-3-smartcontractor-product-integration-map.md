# GCSC Whitepaper v1.3 SmartContractor Product Integration Map

Status: internal product integration map. This does not approve production release, public publication, live Supabase changes, provider outreach, legal conclusions, real payments, real loans, escrow custody, stablecoin settlement, token collateral, FIO registration, wallet signatures, XPR signatures, or Metallicus/XPR/WebAuth/Metal partnership claims.

## Purpose

This map translates the v1.3 Construction Trust Infrastructure strategy into SmartContractor product modules without enabling real finance or regulated Web3 activity.

SmartContractor should show normal construction software first: project records, contractor profiles, bids, project contracts, milestone evidence, dispute packets, reputation context, request IDs, admin review notes, and provider-ready handoff packets.

## Product Module Map

| SmartContractor Module | v1.3 Concept | Current Allowed Product Treatment | Blocked Live Treatment |
|---|---|---|---|
| Homeowner project intake | Construction trust workflow | Local/demo project request with scope, location, budget, status, and request ID | Binding contract, escrow custody, guaranteed pricing, or licensed contractor certification |
| Contractor profile | Verified contractor record | Local profile, business identity fields, license/insurance status notes, and review status | Legal certification, insurance issuance, KYC/KYB approval, or provider-verified badge |
| Bid workspace | Transparent contractor selection | Local bids, bid notes, response timing, and comparison context | Real lead sale, contractor assignment, payment collection, or guaranteed acceptance |
| Project contract record | Escrow-ready agreement evidence | Local project-contract record with parties, terms, amount, and milestone plan | Legal document execution, e-signature request, lien waiver filing, or escrow funding |
| Milestone tracker | Escrow-ready milestone records | Local milestone scope, work status, payment status, evidence refs, and dispute state | Automatic escrow release, on-chain payment release, stablecoin settlement, or lender repayment routing |
| Evidence packet | Completion proof and dispute evidence | Local photo/video/link/note metadata, reviewer notes, and audit trail | Legal liability decision, provider claim adjudication, or fund release |
| Dispute center | Dispute protection workflow | Local dispute record, evidence list, peer review, admin review status, and request ID | Legal arbitration, refund decision, escrow override, or court/lien action |
| Reputation context | Contractor trust score inputs | Local rating, dispute history, repayment history context, bid accuracy, and response timing | Reputation as collateral, investable score, guaranteed underwriting, or credit approval |
| Working-capital readiness | Partner-reviewed financing packet | Local readiness packet for future lender/provider review | GCSC loan origination, instant loan approval, funding, servicing, adverse action, or repayment collection |
| Payment intent record | Payment coordination record | Demo-only payment intent, provider status placeholder, and reconciliation notes | Card charge, ACH movement, payout, XPR transfer, stablecoin settlement, refund, or treasury movement |
| Admin review console | Human/provider gate | Local draft notes, blocker states, review checklist, and no-real-money warnings | Real approval authority, live RLS role change, provider decision, or legal conclusion |
| Future digital construction record | Regulated Web3 record path | Future/review-required record reference and non-value audit-hash design | Public NFT marketplace, token collateral lock, transferable investment asset, or public yield claim |
| FIO Protocol UX | Future identity/request usability | Future optional FIO Handle/request UX research only | FIO registration, live FIO payment request, payment approval, KYC/KYB, escrow, or lending function |
| XPR/WebAuth/Metallicus path | Future regulated Web3 infrastructure | Research/testnet/local architecture references only | Wallet connection required for users, value-bearing XPR signatures, Metal X/LOAN integration, or partnership claim |

## Required Product Data Boundaries

Every SmartContractor product integration row must preserve these boundaries:

- local/demo records are allowed;
- provider-ready packets are allowed;
- request IDs and audit logs are allowed;
- demo-only payment and loan records are allowed;
- future/review-required Web3 references are allowed only with blocked-live context;
- no real money movement is allowed;
- no real lending, escrow, insurance, appraisal, custody, KYC/KYB approval, legal decision, or provider decision is allowed;
- no FIO registration, XPR signature, stablecoin settlement, token collateral lock, minting, staking, bridge, swap, or transfer is allowed;
- no Metallicus, XPR, WebAuth, Metal, FIO, lender, escrow, insurer, bank, appraiser, or attorney partnership approval is claimed.

## Provider Handoff Packet Shape

Future provider handoff packets should remain API-neutral until founder/legal/provider review exists.

| Packet | Allowed Fields | Required Review Before Live |
|---|---|---|
| Escrow-ready milestone packet | project ID, milestone ID, scope, amount, evidence refs, dispute state, request ID | escrow provider, state-law review, legal review |
| Working-capital readiness packet | contractor profile, project contract, milestone plan, repayment context, dispute history, rating context | licensed lender/provider review, finance counsel, adverse-action process |
| Verification readiness packet | profile identity fields, business fields, license/insurance refs, user consent status | KYC/KYB/AML provider, privacy review, data minimization |
| Insurance/bonding context packet | contractor business fields, COI refs, project type, claim/dispute context | licensed insurance/broker review |
| Valuation context packet | property context, project scope, before/after evidence, appraisal references | appraisal/provider/legal review |
| Web3 audit proof packet | record hash, timestamp, non-value reference, signer role, request ID | technical/security/legal review before production use |
