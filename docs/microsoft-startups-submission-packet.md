# Microsoft For Startups Submission Packet

Date: 2026-05-04

## Current Microsoft Startup Paths

Microsoft currently describes two relevant paths:

1. Azure startup credit offer: up to `$5,000` in Azure credits, with `$1,000` available immediately for eligible startups.
2. Microsoft for Startups Investor Offer: investor/referral-based path where accepted startups may start with larger Azure credits and may become eligible for more.

## Best Application Position For GCSC

Use SmartContractor as the main product story.

Why:

- it is concrete and easy to understand;
- it has a working MVP;
- it solves a real market problem;
- it explains why Azure AI credits are useful;
- it connects AI, backend infrastructure, payments, database, and security work.

Do not lead with token price, speculation, or investment language.

Lead with:

- homeowner protection;
- contractor trust;
- project-based working capital;
- milestone payments;
- verification;
- dispute evidence and peer review;
- AI agents for matching, risk, and compliance.

## Short Application Answer

```text
GCSC is building SmartContractor, an AI and blockchain-powered construction marketplace that helps homeowners and contractors manage verified bids, milestone payments, working-capital loans, dispute evidence, peer review, and future XPR Network smart-contract settlement. The MVP already includes a local frontend, backend API, Supabase database schema, payment router, verification layer, audit ledger, loan/repayment flow, dispute workflow, and GitHub Actions CI.
```


## Step-By-Step For Founder Later

When you are ready to apply:

1. Open this page: `https://www.microsoft.com/en-us/startups`.
2. Click `Get started` or `Apply`.
3. Sign in with the Microsoft account you want to use for the startup.
4. Use project name: `Global Construction Smart Contract`.
5. Use product name: `SmartContractor`.
6. Use website: `https://xprnet.org`.
7. Use business email: `gcsc@xprnet.org`.
8. Copy the summary from `docs/microsoft-startups-application-draft.md`.
9. If asked for technical details, copy the `Technical Stack` and `AI Use Cases` sections.
10. If asked how credits will be used, copy the `Why Microsoft Azure / AI Credits Matter` section.
11. Do not enter wallet private keys, database passwords, Namecheap password, or payment provider secrets.

## Risks To Avoid In The Application

- Do not promise guaranteed token price growth.
- Do not say real loans are already live.
- Do not say production payments are already fully approved.
- Do not upload private keys or secret files.
- Do not present the MVP as a regulated lending product until attorney review is complete.

## Recommended Next Move

Submit the basic Azure startup credit offer first if available, because it may provide immediate credits with less friction.

Then pursue the larger Microsoft for Startups / investor path after:

- the demo is recorded;
- GitHub Pages HTTPS is stable;
- SmartContractor MVP is deployed beyond localhost;
- the founder one-pager is polished;
- a short pilot plan is ready.
