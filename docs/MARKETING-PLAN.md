# GCSC Marketing & Launch Plan

**Дата:** 2026-06-26
**Контекст:** реклама проекта **после** успешного бета-теста в Seattle (≈ 8 недель после старта Sprint 1).
**Аудитории:** контракторы, homeowners, XPR/crypto community, инвесторы.

## Принципы

1. **Не запускать маркетинг ДО рабочего testnet flow.** Привлечь трафик на сломанный продукт = сжечь репутацию.
2. **Hybrid messaging.** Первый этап — «trust infrastructure для строительной индустрии». Web3/token — long-term vision, не hook. После CLARITY/GENIUS Act — крипто-нарратив агрессивнее.
3. **Локальный фокус.** Seattle первые 3 месяца. Один город = доказательство концепта = инвесторам и партнёрам конкретные цифры.
4. **Two-sided marketplace.** Сначала контракторы (supply), потом homeowners (demand).
