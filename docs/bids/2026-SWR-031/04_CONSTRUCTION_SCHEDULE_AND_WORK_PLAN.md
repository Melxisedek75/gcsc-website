# Construction Schedule And Work Plan

Contract duration: 42 calendar days from Notice to Proceed, plus 5 calendar days for final completion if allowed by contract.

## Schedule Summary

| Phase | Target Days | Work |
|---|---:|---|
| Preconstruction | Days 1-7 | Submittals, background checks, material procurement, site logistics, confirmation of field dimensions. |
| Mobilization / protection | Days 8-10 | Protection, access controls, temporary barriers, dust control, delivery staging. |
| Selective demolition | Days 11-14 | Remove affected finishes, salvage designated granite/terrazzo/stainless items, expose conditions. |
| Framing / rough work | Days 15-21 | Cold-formed metal framing, anchorage, rough opening verification, ceiling support adjustments. |
| Frames / glazing coordination | Days 18-30 | Hollow metal frame installation, fire-rated glazing coordination, field verification, inspections. |
| GWB / CBB / finish base | Days 22-32 | Type X GWB, CBB where required, taping, Level 5 finish in visible areas. |
| Finish restoration | Days 30-38 | Granite/terrazzo reinstall, stainless trim, sealants, acoustic ceiling repair, paint-ready completion. |
| Punch / closeout | Days 39-42 | Owner/architect punch, cleaning, labels, documents, closeout. |
| Final completion | Days 43-47 | Final punch resolution, if required. |

## Work Approach

1. Confirm all field dimensions before ordering final glazing and frame components.
2. Treat the public lobby as an occupied facility work zone.
3. Maintain clean access routes and protect adjacent finishes daily.
4. Coordinate noisy/dust-producing work with Pierce County building operations.
5. Preserve existing granite/terrazzo elements marked for reuse.
6. Verify fire-rated assembly requirements before covering work.
7. Document concealed conditions with photos before proceeding.
8. Complete closeout with product data, inspection records, and punch completion.

## Procurement Priority

Order or reserve these immediately after award:

- Fire-rated glazing.
- Hollow metal frames.
- Stainless steel trim.
- Specialty sealants.
- Matching ceiling tile/grid components.
