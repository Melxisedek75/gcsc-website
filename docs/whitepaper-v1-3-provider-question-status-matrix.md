## Safe Routing Rule

Codex may prepare local packets, redaction checklists, status matrices, and response templates.

Codex must not contact reviewers, providers, vendors, attorneys, banks, insurers, appraisers, regulators, FIO, XPR, Metal, WebAuth, Metallicus, payment processors, lenders, or escrow providers autonomously.

## Stop Boundary

This matrix does not approve:

- replacing `whitepaper.html`;
- replacing `index.html`;
- publishing a PDF;
- sending provider outreach;
- claiming a provider response has been received;
- claiming founder, legal, provider, publication, or live-action clearance;
- claiming partnership commitments;
- activating any live payment, loan, escrow, stablecoin settlement, token collateral, wallet signature, FIO registration, or production Web3 action.
