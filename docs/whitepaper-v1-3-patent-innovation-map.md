# GCSC Whitepaper v1.3 Patent And Innovation Map

Status: internal innovation map. This is not patent advice, legal advice, or a patentability opinion.

## Purpose

This map preserves the most defensible GCSC innovation areas after the Mirofish simulations and v1.3 repositioning.

## Stronger Innovation Areas

| Area | Why It May Matter | Safer Framing |
|---|---|---|
| Construction Trust Score | Combines project, milestone, dispute, license, evidence, and repayment signals | Reputation and underwriting data layer |
| Milestone Verification Layer | Structures evidence and review before payment or financing actions | Human/provider-reviewed milestone evidence |
| Value Mirror Records | Links verified work to measured improvement and performance history | Digital construction value record, not investment return |
| Contract-Backed Working-Capital Packet | Converts signed project and milestone data into lender-ready package | Lender/provider-reviewed data package |
| Repayment Waterfall Logic | Routes approved milestone proceeds through repayment-first calculations | Future provider-reviewed payment workflow |
| Dispute Pause Controls | Freezes sensitive actions when dispute evidence exists | Consumer-protection and audit mechanism |
| AI Evidence Summaries | Helps reviewers compare milestone claims with uploaded evidence | AI assistance, not final authority |
| Contractor Performance Credential | Portable proof of completion and quality | Restricted credential or reputation record |
| Escrow-Ready Milestone Schema | Standardizes construction escrow status without holding funds | Licensed-partner interface |
| Web3 UX For Construction Records | Optional FIO/WebAuth/XPR handle and audit reference layer | Future regulated Web3 usability |

## Weaker Innovation Areas

| Area | Reason |
|---|---|
| Generic token sale | Common, high regulatory risk |
| Generic NFT marketplace | Common, speculative framing risk |
| Generic contractor marketplace | Crowded market |
| Generic escrow app | Licensing and competition risk |
| Generic lending platform | Licensing and underwriting risk |

## Patent Review Questions

1. What is novel about combining milestone evidence, trust scoring, and working-capital readiness?
2. Can Value Mirror be claimed as a data-record process without claiming investment value?
3. Can dispute pause and repayment waterfall rules be protected as workflow logic?
4. Can contractor performance credentials be protected as a construction-specific identity layer?
5. Can FIO/WebAuth/XPR construction record UX be protected only as integration pattern, not underlying protocol ownership?

## Filing Boundary

Codex must not file patents, make patentability claims, contact patent counsel, or publish invention details externally without founder approval.
