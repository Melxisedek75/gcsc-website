# SmartContractor Smart Contract Audit Event Map

Status: internal audit-event mapping draft only. Not deployed. Not legal advice. This map does not approve real escrow, does not approve real loans, does not approve token collateral, does not approve production payments, and does not approve live XPR contract deployment.

## Purpose

Map future smart contract actions and state transitions to audit events before any code is written or deployed. The goal is to keep project escrow, contractor credit, repayment waterfall, token collateral, peer review reward, dispute pause, emergency pause, and authority flows traceable in the backend and future XPR contracts.

Every event is local-only until founder approval, legal/provider review, security review, no-real-money tests, XPR account approval, and production provider gates are complete.

## Event Naming Rules

- Event names use lowercase dot notation: `module.object.action`.
- Names describe ledger facts, not legal conclusions or money movement.
- Use `recorded`, `label_recorded`, `recommended`, `blocked`, or `paused` when the system is not legally allowed to execute the real action.
- Do not use event names that imply approved lending, licensed escrow, stablecoin settlement, liquidation, repayment routing, or token reward issuance unless provider/legal/founder gates are complete.
- Every state transition must create an audit event.
- Every authority change must create an audit event.
- Every event must include a request id so backend logs, API responses, dispute records, and future chain tables can be correlated.

## Required Audit Fields

Each future audit fixture or smart contract table row should preserve these fields where applicable:

| Field | Required Use |
|-------|--------------|
| `event_id` | Unique event key for backend and future chain correlation |
| `request_id` | Links API response, backend log, evidence, and audit record |
| `module` | `project_escrow`, `loan_ledger`, `token_collateral`, `peer_review`, or `authority` |
| `actor_account` | Local fixture account or future XPR actor account |
| `actor_role` | homeowner, contractor, reviewer, inspector, admin, founder_multisig, provider_signer, security_signer, or system |
| `action_name` | Draft action from the action register |
| `previous_state` | State before transition |
| `next_state` | State after transition |
| `project_contract_id` | Project contract reference when applicable |
| `milestone_id` | Milestone reference when applicable |
| `loan_id` | Contractor credit or loan ledger reference when applicable |
| `collateral_id` | Token collateral fixture reference when applicable |
| `review_id` | Peer review or inspector review reference when applicable |
| `evidence_id` | Evidence file/metadata reference when applicable |
| `safety_gate` | Demo-only, founder-review, legal-review, provider-review, security-review, or blocked |
| `provider_review_status` | pending, required, approved, rejected, or not_applicable |
| `founder_approval_status` | pending, required, approved, rejected, or not_applicable |
| `legal_provider_status` | pending, required, approved, rejected, or not_applicable |
| `created_at` | Timestamp generated by backend or future chain table |

## Project Escrow Events

| Event | Trigger | State Link | Safety Meaning |
|-------|---------|------------|----------------|
| `contract.project.created` | Accepted bid becomes project contract | `draft` to `pending_review` | Records contract creation only; no escrow is held |
| `contract.milestone.added` | Milestone is attached to project contract | `pending_review` | Records milestone structure only |
| `contract.milestone.evidence_submitted` | Contractor submits work evidence | `active` to `milestone_submitted` | Starts review path; no payment release |
| `contract.milestone.review_recorded` | Inspector, peer reviewer, or admin records review | `under_review` to `release_recommended` or `disputed` | Recommendation only |
| `contract.project.paused` | Dispute, emergency, or authority gate pauses project | any non-terminal state to `paused` | Stops release path without moving money |
| `contract.project.dispute_resolved` | Dispute review result is recorded | `disputed` to `under_review`, `release_recommended`, or `cancelled` | Records outcome; does not release escrow |
| `contract.project.completed_label_recorded` | All demo milestones are marked completed | `release_recommended` to `completed` | Label only until provider/legal gates pass |

## Loan Ledger Events

| Event | Trigger | State Link | Safety Meaning |
|-------|---------|------------|----------------|
| `loan.request.recorded` | Contractor requests working-capital review | `requested` | No loan approval |
| `loan.score.recorded` | Risk score or underwriting input is calculated | `scoring` | Advisory score only |
| `loan.provider_review.recorded` | Finance/provider review status changes | `provider_review` | Provider decision placeholder only |
| `loan.offer.recorded` | Offer terms are drafted | `offer_recorded` | Draft terms only |
| `loan.repayment_plan.recorded` | Repayment-first waterfall is attached | `repayment_plan_recorded` | Planned waterfall only |
| `loan.repayment_event.recorded` | Simulated milestone allocation is logged | `repayment_event_recorded` | No real repayment routing |
| `loan.default_label.recorded` | Demo default label is added | `default_label` | Label only; no collection action |
| `loan.repaid_label.recorded` | Demo repayment completion label is added | `repaid_label` | Label only |
| `loan.declined.recorded` | Request is declined in demo/provider review | `declined` | Records non-approval |

## Token Collateral Events

| Event | Trigger | State Link | Safety Meaning |
|-------|---------|------------|----------------|
| `collateral.demo_lock.recorded` | Demo collateral estimate is attached | `demo_locked` | No real token lock |
| `collateral.price_snapshot.recorded` | Oracle placeholder or market snapshot label is captured | `price_snapshot_recorded` | Placeholder only |
| `collateral.ltv_check.recorded` | LTV label is calculated | `ltv_checked` | Risk label only |
| `collateral.release_label.recorded` | Demo collateral release label is recorded | `release_label_recorded` | No real release |
| `collateral.liquidation_blocked` | Liquidation path is attempted or reviewed | `liquidation_blocked` | Confirms auto-liquidation is blocked |

## Peer Review Reward Events

| Event | Trigger | State Link | Safety Meaning |
|-------|---------|------------|----------------|
| `peer.review.submitted` | Reviewer submits evidence and recommendation | `submitted` | Review record only |
| `peer.review.score_recorded` | Review score is stored | `scored` | Reputation signal only |
| `peer.review.reward_label.recorded` | Demo reward eligibility is labeled | `reward_label_recorded` | No real token reward |
| `peer.review.abuse_flagged` | Conflict, spam, or suspicious review is flagged | `abuse_flagged` | Sends to admin review |
| `peer.review.paused` | Reward/review module is paused | `paused` | Stops reward labeling |

## Authority And Safety Events

| Event | Trigger | Required Actor | Safety Meaning |
|-------|---------|----------------|----------------|
| `authority.module.paused` | Module is paused | admin, founder_multisig, or security_signer | May stop activity only |
| `authority.module.unpaused` | Module is reopened | founder_multisig plus required signer | Stronger approval than pause |
| `authority.changed` | Authority list or permission changes | founder_multisig plus security_signer | Must be reviewed before deployment |
| `authority.multisig.recorded` | Multisig approval evidence is attached | founder_multisig | Evidence only until deployment |
| `authority.emergency_pause.recorded` | Emergency pause is triggered | security_signer or founder_multisig | Must not move funds or decide loans |
| `authority.provider_gate.recorded` | Provider approval status is attached | provider_signer | Provider status only |
| `authority.founder_approval.recorded` | Founder approval evidence is attached | founder_multisig | Internal approval evidence only |

## Not Allowed

This audit event map must not be used to:

- move real funds;
- approve real loans;
- release real escrow;
- route real repayments;
- lock real token collateral;
- settle stablecoins;
- issue real rewards;
- liquidate collateral;
- let AI make final approval, release, default, liquidation, or dispute decisions;
- claim SmartContractor is a licensed lender, bank, escrow agent, payment provider, underwriter, broker, or legal advisor.
