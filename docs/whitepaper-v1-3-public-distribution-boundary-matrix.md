# GCSC Whitepaper v1.3 Public Distribution Boundary Matrix

Status: internal public distribution boundary matrix. Current publication and distribution decision remains NO-GO.

This matrix does not approve public publication, public website replacement, PDF publishing, deck/social/email distribution, reviewer outreach, provider outreach, investor/grant packet distribution, legal conclusions, provider commitments, live Supabase changes, real payments, real loans, escrow custody, stablecoin settlement, token collateral, wallet signatures, FIO registrations, XPR signatures, or Metallicus/XPR partnership claims.

## Purpose

This matrix keeps local review work separate from public distribution. It defines what can stay local, what can be prepared for founder review, and what requires a separate dated GO decision before anything leaves the repo or changes a public route.

## No Shortcut Rules

- A local draft is not a public release.
- A local PDF candidate is not a published PDF.
- A founder review packet is not a publication decision.
- A reviewer packet template is not reviewer outreach.
- A public announcement template is not announcement approval.
- A clean validator run is not legal/provider clearance.
- A distribution matrix is not authority to send, upload, publish, or route anything.

## Stop Boundary

Stop before uploading, emailing, posting, publishing, routing, sending, sharing externally, changing public website files, contacting reviewers or providers, making legal conclusions, touching live systems, moving money, approving loans, holding escrow, settling stablecoins, locking token collateral, registering FIO names, or signing XPR actions.
