## Reviewer Response Intake

Each reviewer response should be recorded with:

| Field | Required |
|---|---|
| reviewer type | yes |
| reviewer name/company | founder-controlled |
| date | yes |
| files reviewed | yes |
| decision | HOLD / REVISE / APPROVE_PUBLIC_SAFE_WORDING / BLOCK_FOR_LIVE_USE / NO_GO |
| required changes | yes |
| limits of review | yes |
| public wording approved? | yes/no |
| live action approved? | must remain no unless founder/legal/provider process separately approves |

## Stop Boundary

This index does not approve:

- sending any packet;
- public publication;
- replacing `whitepaper.html`;
- replacing `index.html`;
- provider partnership claims;
- legal conclusions;
- live lending, escrow, payments, stablecoin settlement, token collateral, wallet signatures, FIO registrations, or production Web3 actions.
